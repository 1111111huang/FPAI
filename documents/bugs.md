# FPAI Bug Tracker

This document tracks bugs and issues discovered during development and testing. Default status is `open`.

| Bug ID | Title | Description | Status | Notes |
| :--- | :--- | :--- | :--- | :--- |
| BUG-001 | Missing xG and LUCK features blocking training | Feature factory generates xG and LUCK features derived from xG data (luck = fthg - xg_h), but raw_matches table had no xG data initially. When xG is missing, these features become NaN and are stored as string "nan" in DuckDB, causing all training rows to be dropped during dropna(). | fixed | Removed xG_R3/R5, XGA_R3/R5, LUCK_R3/R5 features from schema.yaml selected_features. These will be re-added once Understat integration provides xG data. |
| BUG-002 | Schema.yaml included unsupported features dependent on missing data | Configuration referenced 28 features (xG, XGA, LUCK variants) that cannot be generated without source xG data from ingestion. | fixed | Feature set reduced from 92 available features to 62 data-complete features. Updated config/schema.yaml to remove xG/LUCK-dependent features. |
| BUG-003 | Sklearn mean_squared_error squared parameter compatibility | Regression model evaluation failed: `mean_squared_error(..., squared=False)` threw TypeError about unexpected keyword argument. The sklearn API differs across versions. | fixed | Changed to compute MSE first, then apply np.sqrt() for RMSE. This is compatible across sklearn versions. |
| BUG-004 | Model comparison missed split metrics with suffix-style names | MLflow runs could log metrics as `log_loss_test` while comparison expected `test_log_loss`, causing incomplete comparison reports. | fixed | `ModelComparison.extract_metrics_for_run()` now normalizes both prefix and suffix split metric styles. |
| BUG-005 | XGBoost classifier failed on string multiclass labels | `result_3way` uses labels such as `home`, `draw`, and `away`; XGBoost expected integer class IDs and failed during smoke sweep training. | fixed | `XGBoostModel` now label-encodes classifier labels during training and inverse-transforms predictions. Loss evaluation reads the wrapper class order. |
| BUG-006 | XGBoost multiclass sweep used binary logloss defaults | A multiclass smoke sweep failed because XGBoost received a binary `logloss` evaluation metric for `result_3way`. | fixed | `SweepRunner` now sets task-aware XGBoost objectives/metrics: `multi:softprob`/`mlogloss` for multiclass and `binary:logistic`/`logloss` for binary. |
| BUG-007 | Local MLflow file store has malformed experiment directories | CLI and experiment runs repeatedly warn that `mlruns/1` through several local experiment folders are missing `meta.yaml`. Runs still complete, but logging is noisy and slower. | fixed | Implemented `cleanup-mlflow` CLI command (user story 50) to repair malformed experiments. Successfully recovered 9 malformed experiments by creating minimal meta.yaml files. |
| BUG-008 | Matplotlib/font cache directory is not writable in local environment | Experiment and test commands warn that `/Users/tianqihuang/.matplotlib` and some fontconfig cache directories are not writable, forcing cache rebuilds. | open | Non-fatal. Consider setting a writable `MPLCONFIGDIR` in local dev/test commands. |
