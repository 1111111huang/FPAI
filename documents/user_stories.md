# FPAI Forecast Engine User Stories

This document tracks story-level actionable items for the forecast-engine pivot. Default status is `active`.

## Story Dependencies & Execution Order

To ensure dependencies are respected, work on stories in these priority groups:

**PHASE 1: Measurement Infrastructure (FOUNDATION)**
- **US#35** → Add Train/Val/Test Split Metrics (completed)
- **US#38** → Add validation tests (completed)

**PHASE 2: Model Comparison Tools (Enable variant exploration)**
- **US#36** → Build Model Comparison Tool (completed)
- **US#37** → Add Evaluation Diagnostics (completed)
- **US#41** → Build Sweep Framework (completed)

**PHASE 3: Model Expansion (Test new architectures)**
- **US#39** → Add XGBoost Classifier (completed for implementation and smoke coverage; broad-grid review pending)
- **US#40** → Add Gradient Boosting Regressors (completed for implementation and smoke coverage; broad-grid review pending)
- **US#42** → Model Selection Logic (PAUSED - manual inspection for now, auto-selection later)

**PHASE 4: Feature Enhancement (Unlock potential)**
- **US#43** → Complete Understat Integration (PAUSED - deferred to later phase)
- **US#44** → Maintain Team Mapping (PAUSED - depends on US#43)
- **US#45** → Add xG-Based Features (PAUSED - depends on US#43)
- **US#46** → Add Feature Interactions (completed)

**PHASE 5: Feature Analysis & Documentation**
- **US#47** → Run Permutation Importance (depends on US#39, US#40)
- **US#48** → Feature Selection Study (depends on US#47)
- **US#49** → Update Technical Spec (depends on US#36, US#37, US#47)
